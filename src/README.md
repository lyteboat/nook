# Nook：我的 AI 指南针

> 磨刀不误砍柴工。

Nook 是一个安静的角落。我在这里持续学习 AI，把零散的问题、思考和外部世界的新进展，慢慢沉淀成一本结构完整的书。

它不是一份资讯合集，而是一张**地图**：当我在模型、Agent、数据、工程化，或者金融与医疗的 AI 产品里迷路时，翻开它能找到方向。

## 这本书怎么长出来

书稿有两路输入：

1. **我的输入**：日常的问题、想法、讨论和实践。
2. **外部输入**：每周三、周六两次的 AI 动态雷达，覆盖官方博客、论文、开源项目与技术社区。

两路输入先进入草稿池或雷达存档，经过讨论和提炼，再归档到对应章节。详见[前言](preface.md)。
