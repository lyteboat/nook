# 随笔

Yue 随手写的想法和素材，以后整理进书里，也会单独发在站点的「随笔」页。

## 在线写（推荐）

打开 <https://lyteboat.github.io/nook/admin/>，第一次在这台设备上点「使用访问令牌登录」，粘贴 GitHub 令牌。「使用 GitHub 登录」按钮要另配登录中转，目前用不了。编辑页左边有两栏：

- **随笔**：新建、修改、删除随笔。只有四项：标题、状态、用于哪一章（可空）、正文。文件名按新建那天的日期和时间自动生成。
- **书稿**：按 `src/SUMMARY.md` 的顺序列出书的每一页，点开直接改正文。新增章节、调整顺序要改目录，交给 Claude。

每次保存直接提交到 main，1 到 2 分钟后站点更新。

- 状态选「草稿」的不上站点，改成「已发布」再保存，所有人不用登录就能看。草稿只是不上站点，仓库是公开的，在 GitHub 上仍看得到。
- 预览默认在右边。点右上角「保存」旁边的 ⋮，取消「显示预览」就能关掉，编辑页会记住这个设置。
- 图片存在 `notes/images/`。
- 令牌在 <https://github.com/settings/personal-access-tokens/new> 建：Resource owner 选 lyteboat，Repository access 只选 nook，Permissions 里 Contents 设为 Read and write，有效期最长一年，过期后重建一个再登录。

## 文件格式

每篇一个 Markdown 文件：`notes/YYYY/YYYY-MM-DD-短名.md`，短名只用小写字母、数字和连字符，编辑页生成的是时间，比如 `2026-11-27-0336.md`。开头两行 `---` 之间写标题、状态和用于哪一章，下面写正文，格式见 [`_template.md`](_template.md)。

- 状态为「草稿」的不发布，其余合并到 main 后自动发布：首页底部列最新 6 篇，「随笔」页按年列出全部，每篇有自己的页面和上一篇、下一篇翻页。文件名不符合格式的不会发布。
- 构建脚本把 Markdown 转成 HTML，样式由站点统一提供。支持标题、段落、列表、引用、代码块、分隔线、加粗、斜体、链接和图片。
- 旧格式也认：文件头里的「写法」「引用」照旧生效，标题也可以写成正文第一行的 `#`。

## 其他写法

- 在 GitHub 网页上：进 `notes/` 目录点 Add file → Create new file，文件名填 `2026/2026-11-06-xxx.md`，粘贴模板改写后提交。
- 交给 Claude：把要写的内容发给它，说“记成随笔”，它按模板整理好开 PR。
