# 专题

专题把雷达里反复出现的一个话题写透，一篇讲一个技术方向、一个行业或一种做法，和雷达一样按招熟、懂劲、神明三阶段组织。

- 每篇一个文件：`topics/YYYY/YYYY-MM-DD-英文短名.html`，日期是首次发布那天。复制 [`_template.html`](_template.html)，模板开头的注释写明了每个小节写什么、写几条、多少字。
- 版式是讲义：左侧固定目录，小节编号固定，从 00 要点到 09 来源。读者读第二篇时，同一类信息还在同一个位置。
- 类型三选一：技术专题、行业专题、方法专题。三类的小节顺序相同，只有版图的分组方式不同。
- 封面的 `data-after` 写延伸自哪一期雷达，`data-tags` 写一到三个标签，站点按标签在“待解问题”和“来源”之间列出相关雷达条目。
- 专题可以跨期更新：改封面日期，在时间线和版图里加新条目。
- 合并到 main 后自动发布：首页挂在对应那一期下面，“专题”页按时间列出全部。文件名不符合格式的不会发布。
