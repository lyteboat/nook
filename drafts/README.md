# 草稿池

这里是**临时区**：还没想清楚的问题、零散的想法、讨论片段、读到的好文章摘录。

## 规则

- 新草稿放进 `inbox/`，文件名：`YYYY-MM-DD-简短主题.md`，例如 `2026-10-23-agent-记忆设计.md`。
- 复制 [`_template.md`](_template.md) 开始写，填好头部的“目标章节”和“状态”。
- 每周六盘点一次，每份草稿只有三种去向：**归档**、**保留**、**删除**。
- 创建超过 30 天仍未归档的草稿，必须在盘点时决定去向；保留需写明理由，最多延期一次。
- 归档后删除原草稿，不在这里留副本。

完整流程见 [`../meta/workflow.md`](../meta/workflow.md)。
