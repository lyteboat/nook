Agent 的建议会悄悄变成人的决定，把关要靠独立的复核

英国 80% 的金融机构已部署 Agent。Anthropic 的随机试验里，分析师在 86% 的开放决策上跟着 Agent 的倾向走，只有 15% 承认参考过它。换一个独立的评审 Agent，Terminal-Bench 准确率提高 5.9 到 9.5 分；在 200 例活检确诊的皮损上，十年前的专用 CNN 首诊准确率 62%，两款前沿大模型都是 42%。

技术 1懂劲医疗皮肤癌诊断：专用 CNN 对前沿 LLM

Magnus Lynch｜用 200 例难例对比 CNN 与大模型

医疗判别任务上，小而专的模型仍比通用大模型准

What是什么
皮肤科医生 Magnus Lynch 用 200 例活检确诊的皮损，比较 2015 年的 Inception v3 与 GPT-6 Astra、Claude Fable 5.1。首诊正确：CNN 125 例（62%），两款大模型 84 例和 85 例（均为 42%）。
Why为什么重要
通用大模型能描述图像，专业判别仍不如小而专的模型。医疗功能选型，要拿同一批病例做对照，不能拿通用模型的演示代替。
How怎么做的
CNN 在 ISIC 的 68,011 张图上微调，单张 H100 约 20 分钟；大模型每例拿到临床照和皮肤镜照各一张，只跑一次。大模型偏保守：GPT-6 Astra 留住了 97 例不该放走的病变，但只放走 32 例良性病变，CNN 在预设阈值下放走 76 例。局限：黑色素瘤只有 30 例；全是活检过的难例；数据集 2025 年已公开，大模型可能见过。
Who谁
伦敦 Guy's 医院的 Magnus Lynch。分析和初稿用 Claude Code 完成，被测模型之一也来自 Anthropic。
When何时
10-25 发在作者的实验室网站，未经同行评审。病例、提示词和评分代码可下载。Hacker News 首页 331 分。
Action我们做什么
医疗影像功能先建一套有病理金标准的难例集；任何大模型方案都和一个专用小模型基线在同一批病例上比较；准确率之外，单独统计漏放和过度转诊两类错误。

原文：A 10-year-old CNN outperforms frontier LLMs for skin cancer diagnosis（Lynch Lab），10-25

技术 2招熟Agent 自检设计对比

Zhang 等人｜比较 Agent 的 17 种自检设计

让另一个 Agent 独立复核，比在提示词里反复提醒更划算

What是什么
一篇预印本把 Agent 的自检分成四层：初始指令、中途提醒、完成门槛、独立评审，在七个前沿编程模型上比较了 17 种设计。
Why为什么重要
自检和执行共用一个上下文，容易沿用同一个错误。评审者换一个干净的上下文，才是真正的第二双眼睛。测试时算力（test-time compute）花在哪一层，这篇给了可量化的答案。
How怎么做的
独立评审在 Terminal-Bench 上把平均准确率提高 5.9 到 9.5 分，成本是基线的 1.13 到 1.25 倍；在 SWE-bench Verified 上提高 3.9 到 6.6 分，成本是基线的 1.00 到 1.04 倍。初始指令和中途提醒收益小，且因模型而异；完成门槛收益更大，但可能大幅推高成本。只测了编程任务。
Who谁
Zhengxin Zhang、Erkang Zhu、Yin Lin、Claire Cardie、Bolin Ding、Jingren Zhou。
When何时
10-25 提交 arXiv，预印本。
Action我们做什么
金融、医疗 Agent 交付结果前加一道独立评审：评审者用新上下文，只看任务、产出和证据；评审通过率和新增成本一起进评测看板。

原文：Rethinking Verification in Agent Harnesses（arXiv），10-25

产品 1懂劲Agent 左右专家判断的 RCT

Anthropic｜随机试验 Agent 如何左右专家判断

人在回路不等于独立复核，专家会被 Agent 带着走而不自知

What是什么
Anthropic 的随机对照试验：50 名专业分析师用 Claude Code 做一项因果分析。四个方法决策各有两个说得通的选项，Agent 在每个决策上的倾向由抛硬币暗中设定。
Why为什么重要
人在回路（human-in-the-loop）假定人的判断是独立的复核。没有标准答案的判断题上，人会被 Agent 带着走，错误检查和参考答案都查不出来。授信、诊疗里这类判断很多。
How怎么做的
分析师与 Agent 倾向一致的比例是 86%，随机基线 50%。Agent 倾向推广时，54% 的人建议推广；倾向相反时只有 36%。事前有偏好的 38 例里，Agent 反对时 60% 改了主意，赞同时只有 6%。77% 的人在事后解释里复述了 Agent 的论证，只有 15% 提到参考了它，没有人察觉倾向是设定的。局限：倾向是刻意加强的；只有一个任务、一个领域、一个模型，时长约一小时。
Who谁
Anthropic 对齐团队的 Amaç Herdağdelen、Hailey Joren、Alex Tamkin。
When何时
10-27 发布。
Action我们做什么
需要人拍板的决策，先让人写下初步判断，再展示 Agent 的意见；让 Agent 为每个选项给出最强的论证，不只推荐一个；在流程里写明哪些决策必须由人独立做出。

原文：How AI agents shape experts’ judgment calls（Anthropic），10-27

产品 2招熟金融英国金融业 AI 调查 2026

英格兰银行、FCA｜发布 2026 年金融业 AI 调查

Agent 已在金融业普及，自主权仍然很窄

What是什么
英格兰银行（BoE）和金融行为监管局（FCA）的第三次金融业 AI 调查：196 家机构回复，86% 在用 AI（2024 年为 75%），生成式 AI 占全部 AI 系统的 56%。
Why为什么重要
这是监管机构给出的行业基线：Agent 已经普及，自主权仍然很窄。金融 Agent 按这个分寸设计，更容易过合规。
How怎么做的
80% 的机构部署了 Agent，14% 计划一年内部署。按自主程度：决策支持 80%、受限执行 46%、有条件自主 22%、广泛自主 2%。连同计划在内，最多 9% 的机构准备让 Agent 审批客户、下单、划款或改额度。第三方系统占高重要性系统的 53%（2024 年为 35%）；对这类系统，只有 24% 的机构真正了解内部，81% 依赖供应商的保证和合同。两次调查的样本和问法不同，同比数字要谨慎看。
Who谁
英格兰银行和 FCA。
When何时
10-26 发布。这项调查始于 2019 年，2022、2024 年各做过一次。
Action我们做什么
Agent 功能按决策支持、受限执行、有条件自主分级，默认停在前两级；给买方准备可审查的模型文档和评测结果，因为多数机构看不到供应商系统的内部；合规材料按报告的风险排序准备，数据保护和安全排第一。

原文：Artificial intelligence in UK financial services - 2026（Bank of England）；BoE/FCA AI survey 2026: agents widespread, autonomy limited（Resultsense）；UK FS sector embraces GenAI（Finextra），10-26

Max Woolf｜梳理 OpenAI、Anthropic 八次降价Agent 成本的大头是缓存读取，成本模型要定期重算招熟
What是什么
Max Woolf 整理了 7 月底到 9 月底两家的八次调价：GPT-5.6 Luna 降 80%；GPT-6 Sol 比打折后的 GPT-5.6 Sol 再减半；Opus 5.5 输入、输出降 20%，缓存读取从 0.50 美元降到 0.20 美元。
Why为什么重要
模型越来越接近大宗商品，切换成本低，价格在向边际成本靠拢。按 token 算的成本模型要定期重算。
How怎么做的
Agent 编程场景里，缓存读取占 token 支出的 96% 到 99%，缓存价降 75%，总成本约降 70% 到 75%。Vercel 的数据：每 token 成本降到 4 月的 43.3%，总支出仍在涨，因为用量涨得比价格降得快。作者认为原因是两家互相跟价，加上开放权重模型的压力，DeepSeek V4.1 Flash 已有 29 家托管商。
Who谁
Max Woolf（minimaxir），个人博客。
When何时
10-25 发布，价格截至 9-29。
Action我们做什么
成本模型里把缓存读取单列一行；Agent 的提示词保持固定前缀、少改历史，提高缓存命中；选型时把开放权重模型的多家托管价一起比。

原文：OpenAI and Anthropic cut their LLM prices by up to 80% within a few months. Why?（Max Woolf's Blog），10-25

Ai2｜测试大模型能否判断想法新不新模型评审的结论可能取决于提示词怎么写懂劲
What是什么
Ai2 用 ICLR 2026 的评审意见建了一个新颖性评测：154 个高新颖度、145 个低新颖度的人类想法，另配 154 个模型生成的想法。
Why为什么重要
用模型做评审（LLM-as-a-Judge），结论可能主要取决于提示词的措辞。金融、医疗里用模型打分做质检，先要测它稳不稳。
How怎么做的
GPT-5.4 换成更简单的提示词后，准确率从 93.5% 降到 40.9%，过半判定翻转；Claude Opus 4.6 从 100% 降到 72.7%。加检索、加推理没有稳定的改善。最简单的基线，即 Opus 4.6 低推理、三次投票，macro-F1 0.854，总花费 2.59 美元，好过两个专门的评估器。局限：生成想法的标签是假设的，专家只抽查了 30 对。
Who谁
Ai2（艾伦人工智能研究所）。
When何时
10-27 发布。论文是 arXiv 预印本，数据集和代码已公开。
Action我们做什么
自家的模型评审用两三种措辞各跑一遍，统计判定翻转率；先试多次投票这类简单基线，再考虑复杂的评估器。

原文：Can we trust LLMs to judge whether a research idea is novel?（Hugging Face Blog），10-27

西奈山伊坎医学院等｜测试只输出概率的决策模型把决策和语言拆给两个模型，能减少措辞带来的偏差神明医疗
What是什么
一篇预印本测试了两款只输出选项概率、不生成文字的决策模型 Jev 和 OpenAI Decisions，与 GPT-6 Luna 对比，并把两类模型配对使用。
Why为什么重要
病例描述里的标签和催促语会改变分诊结果。把决策和语言交给两个模型，是减少这类偏差的一条工程路线。
How怎么做的
2,134 个病例，约 248 万次调用。临床事实不变、只加标签或压力暗示时，决策模型每 100 个决策多变 13.4 个，大模型多变 14.0 个；配对后降到 2.6 个，开发集降约 81%，留出数据降 42% 到 48%。分诊准确率保持在 81% 到 82%，每千条成本不超过 0.77 美元。只用了合成病例和公开数据。
Who谁
西奈山伊坎医学院、贝斯以色列女执事医疗中心、布莱根妇女医院。作者声明无利益冲突。
When何时
10-24，预印本。
Action我们做什么
分诊、风控功能加一组同事实、不同措辞的扰动测试，量出决策翻转率；评估把决策和生成拆给两个模型的架构。

原文：Decision-only medical AI: early evidence and pairing with language models（medRxiv），10-24
