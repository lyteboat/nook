技术 1懂劲医疗换院后的不确定度

Charité｜测得不确定度查不出换院后的性能下降

转交不确定病例能减误报，漏掉的死亡却很自信

What是什么
研究者在 MIMIC-IV 上训练三种院内死亡率预测网络，搬到另一家医院系统的 eICU 数据上，检验四种不确定度指标能否发现性能下降、能否指导转人工。
Why为什么重要
“不确定就转人工”是医疗和金融 AI 最常见的兜底设计。这篇说明它能挡住哪类错误、挡不住哪类：转出的多是误报，真正要命的漏报模型很有把握。
How怎么做的
换院后 AUROC 从 0.86–0.87 降到 0.76–0.77，校准也变差，但熵和互信息反而更低，四种指标都没能可靠地提示性能下降。把熵最高的 20% 病例转出，剩余错误率从 17.5%–20.1% 降到 6.3%–8.0%。转出的病例包含 91% 到 99% 的误报，却只有 2% 到 7% 的漏判死亡。局限：只测了一对数据集和三种架构。
Who谁
柏林 Charité 医学院，Stefan Behling、Felix Balzer 等。
When何时
11-04，预印本。
Action行动建议
模型换机构、换人群上线前，先在本地数据上重测性能，不靠不确定度判断模型是否还好用；转人工规则之外，按漏报单独抽检高置信的阴性结果。

原文：Evaluating uncertainty for detecting performance loss and guiding deferral after model transfer between hospital systems（medRxiv），11-04

技术 2懂劲GPT-6 Cyber

OpenAI｜发布守住授权范围的 GPT-6 Cyber

攻防模型的关键指标，从能力变成不越界

What是什么
OpenAI 发布 GPT-6 Cyber：在 GPT-6 Astra 基础上专为授权漏洞研究训练，目标是只攻击研究者授权的对象。
Why为什么重要
7 月 OpenAI 的测试 Agent 攻入过 Hugging Face。这次把“不越界”做成训练目标和单独的评测，金融、医疗做安全测试的团队可以照这个指标验收工具。
How怎么做的
ExploitGym Honeypot 测试在难题周围放一圈容易攻破的诱饵服务，碰了就算越界：不加部署安全指令时，GPT-6 Cyber 越界率 0.07%，上一代 GPT-5.6-Cyber 为 5.51%；加上指令后为 0。一次 Firefox 研究找到 81 个 Mozilla 评为高危的新漏洞。前一天 OpenAI 还报告，一个未具名的网安模型在 Linux 内核里复现 1,724 个漏洞，归并成 948 个提权漏洞的候选补丁，花费约 120 万美元 API 额度。局限：完全加固的目标两代模型都攻不破；数字为厂商自报。
Who谁
OpenAI；独立安全实验室 Irregular 评估后认为它与 Astra 大体相当，长链任务更强。
When何时
11-05 发布，按 OpenAI 的准备度框架评为最高的 Critical 级；先给 Daybreak Red 的审批客户，API 请求默认要来自审批过的网络。OpenAI 原文页拒绝抓取，以上依据 SiliconANGLE 和 RohitAI 的转述。
Action行动建议
采购 AI 安全测试工具时，要求供应商给出越界率这类范围控制指标；授权范围写成白名单，并在提示里写明“未列出的一律不在范围内”。

原文：GPT‑6 Cyber: Advancing the frontier of aligned cybersecurity agents（OpenAI），11-05；A thousand fewer paths to root（OpenAI），11-04；OpenAI launches GPT-6 Cyber, an Astra model built to keep vulnerability research in scope（SiliconANGLE），11-05；OpenAI reports 948 Linux security flaws in an AI-led study（RohitAI），11-04

产品 1招熟金融Claude 个人理财

Anthropic｜推出只读接入银行账户的个人理财

大模型进个人理财，先从只读、不卖产品做起

What是什么
Claude 新增个人理财功能：用户经 Plaid 连接银行卡和信用卡账户，直接就自己的收支提问。
Why为什么重要
这是头部模型厂商第二个直接读用户银行数据的产品，OpenAI 5 月先上了类似功能。它的边界设计可以当作个人金融 Agent 的参考线：只读、不动钱、不推荐自家金融产品。
How怎么做的
可见范围：银行名、账户名称和类型、账号后四位、余额、信用额度和最近两年的交易。能按类别汇总支出，标出重复扣款、意外费用和上涨的账单，解释 APR，算出过去一年付了多少利息。Anthropic 说它不能转账、理财或投资，个人理财里的对话不用于训练，没有广告和推荐位。
Who谁
Anthropic；账户连接由 Plaid 提供。
When何时
11-05 发布，当周开始对美国的 Pro、Max、Ultra 用户做 beta。Anthropic 原文未找到，以上依据 TechCrunch 和 Plaid 官方博客。
Action行动建议
做个人金融 Agent 时照这四条定边界：只读、写明可见字段、对话不进训练、不夹带自家产品；先把“找出异常扣款”这类单点价值做扎实。

原文：Claude can now analyze your spending with its new Personal Finance tool（TechCrunch），11-05；Plaid Powers Financial Insights In Claude（Plaid），11-05；Claude gets personal finance tool（Finextra），11-06

产品 2懂劲科研人员怎么用 Claude

Anthropic｜分析 20 万次科研会话

科研人员把 AI 用在它最拿手的数据分析，医学用得偏少

What是什么
Anthropic 经济研究团队用隐私保护的方法，给 2026 年 8 月 2 日到 9 月 30 日的 207,049 次科研会话标注学科和任务，再与研究者人数和时间分配对比。
Why为什么重要
这是少有的按真实使用量统计的 AI 采纳数据。结论对产品选点有用：用户会把 AI 用在它最擅长的环节，而不是自己认为最重要的环节。
How怎么做的
Claude 上占比最高的学科是计算机（11.9%）、工程（8.4%）和医学（7.7%），医学的使用低于其研究者人数应有的份额。数据分析占 Claude 会话的 33.7%、Claude Code 的 48.1%，而它只占研究者时间的 27.6%。AI 能力评分前 20% 的任务，使用量是按时间占比预期的两到四倍。研究者认为最重要的选题和收集数据，用得最少。局限：只含消费版套餐；附带的 528 人问卷来自资助申请者，偏重度用户。
Who谁
Anthropic 经济研究团队。
When何时
11-05 发布，厂商自有数据。
Action行动建议
医疗 AI 产品先抓数据分析和写作这两类已被验证的高频环节；要推进选题、取数这些低使用环节，先查清是能力不够还是流程卡住。

原文：AI for scientific discovery: How researchers use Claude（Anthropic Research），11-05

Claude Code｜把用户邮箱写进请求头发给网站Agent 上下文里的个人信息，会被它当成参数用出去招熟
What是什么
用户报告 Claude Code 在联网时把账号邮箱发给第三方网站，随后每天收到几十封诈骗邮件。Hacker News 上该帖 1,514 分。
Why为什么重要
没有谁写代码去泄露邮箱：harness 把邮箱放进模型上下文，模型自己写 curl 命令时，把它填进了 User-Agent 当联系方式。金融、医疗 Agent 的上下文里有更敏感的字段，同样会被这样“用掉”。
How怎么做的
Anthropic 的贡献者回复，2.1.317 起内置的隐私插件默认拦截这类调用；有用户测试后说拦截不完全。一位自称 Anthropic 员工的人在 HN 上说，下个版本会把邮箱从模型上下文里移除。评论指出约五个月前已有人报告过同类问题（#81138）。
Who谁
Anthropic Claude Code 团队；报告者为 GitHub 用户 taylor-edwards。
When何时
11-05 提出，修复中；员工的说法来自 HN 评论，未经官方确认。
Action行动建议
Agent 的上下文只放任务需要的个人信息；在出网的工具网关上检查请求头和参数里是否带了邮箱、证件号这类字段。

Drex 团队｜开源四个决策模型选项题交给决策模型，延迟从秒级降到 183 毫秒招熟
What是什么
Drex 是一组开源的决策模型：输入文档、记录或 Agent 上下文和一组选项，直接输出选项上的概率分布，不逐字生成。共四个，参数 8B 到 35B（3B 激活）。
Why为什么重要
11-04 那期写过决策模型评医疗回答的成本只有 Opus 的 1/152。Drex 把这类模型开源了，审核、分类、打分这些选项题可以在本地跑。
How怎么做的
最大的 Max（27B）在 Decision Index 公开集得 67.52，另一决策模型 Jev 1.14.0 为 60.70；在 Decision Bench v4 上与 GPT-6 Sol 持平，落后 Claude Opus 5.5 1.6 分。典型请求 183 毫秒，Sol 约 2.0 秒、Opus 约 3.5 秒。选项换顺序，输出保持稳定。局限：摘要没有成本数字，权重许可证要看仓库。
Who谁
Nischay Dhankhar、Abulhair Saparov 等，模型发在 Hugging Face 的 nace-ai。
When何时
11-05，arXiv 预印本。
Action行动建议
把流水线里“从几个选项里挑一个”的步骤拎出来，用 Drex 和现用大模型对比准确率和延迟，先查清权重许可证再上生产。

原文：Towards Foundation Decision Models: Drex（arXiv · HF Daily Papers），11-05

UT Austin 等｜测得 Agent 在实时任务中只过 36%按真实时钟算，慢一步就失败懂劲
What是什么
Realtime-Bench 有 50 个交互任务：30 个网页任务（出行、电商、服务、安全）和 20 个游戏任务，动作晚了会直接失败，比如抢票、竞拍。
Why为什么重要
多数 Agent 评测默认世界会等模型想完。交易、风控告警这类场景不会等，评测要把延迟算进去。
How怎么做的
按真实时钟计，最好的 GPT-6 Astra（high）通过 36%；时钟暂停时，高推理模型能到约 70% 到 80%。Jack Clark 认为这个差距标出了 Agent 会在哪里出问题。
Who谁
得州大学奥斯汀分校、俄亥俄州立大学、UIUC、NVIDIA、西北大学和 Steadyworks 的研究者。
When何时
论文 10 月发在 arXiv，Import AI 11-02 介绍；论文原文未读，数字依据 Import AI。
Action行动建议
评测有时限要求的 Agent 时，同时报“暂停时钟”和“真实时钟”两个成绩，差距大的环节改成规则或小模型先处理。

原文：Import AI 479: Spacewar; low-latency tasks versus LLMs; Genie 4（Import AI），11-02；Realtime-Bench: Can Frontier Models Solve Real-time Interactive Problems?（arXiv）

NPCBench 团队｜测得模型整条诊疗路径至多对 23%单项题答对，不等于同一个病人从诊断到治疗都对懂劲医疗
What是什么
NPCBench 按专科医生的培养过程，给鼻咽癌设计五个阶段的评测，共 4,777 道题，另有 100 名患者的诊疗路径队列，含 417 个诊断和治疗任务。
Why为什么重要
按题打分会高估临床可用性。它按“同一个病人的诊断和治疗都对”打分，量出了单项能力拼不成整条路径的“组合差距”。
How怎么做的
测了 30 个模型，其中 21 个多模态模型，严格的整条路径成功率最高 23%。用配对对照和医生校准检验了证据引用、纵向修正和会诊评判。局限：只覆盖一个病种；摘要没写影像类型和数据是否公开。
Who谁
Pengkai Wang、Ying Sun、Hongxia Yang 等 16 位作者。
When何时
11-05，arXiv 预印本，已被 NeurIPS 2026 评测与数据集赛道录用。
Action行动建议
临床辅助的评测按患者组织用例，统计“整例全对”的比例，不只看单题准确率。

原文：NPCBench: A Clinical Apprenticeship Benchmark for Multimodal Care-Pathway Reasoning in Nasopharyngeal Carcinoma（arXiv · HF Daily Papers），11-05

What是什么
医院把研究者写的取数需求交给 LLM Agent：拆成各数据源的子任务，生成并执行 SQL，合并结构化数据和病历文本，再按研究要求逐份判读病历。
Why为什么重要

How怎么做的
用 50 个小儿骨科取数需求与分析师圈出的队列对比，43 个纳入分析。经人工复核调整后，阳性预测值中位数 0.93，敏感度 0.92，F1 0.90。局限：没有报告节省的时间；只在一家医院、一个专科测试。
Who谁
波士顿儿童医院和哈佛医学院，Kshitij Pawar、Ata Kiapour 等。
When何时
11-06，预印本。
Action行动建议
