模型能力涨得比看管快，边界得提前画好

OpenAI 首席科学家公开了内部的困惑度曲线，提议各家约定一道暂不越过的线，理由是数学成果来得太突然，监控手段跟不上。同一周有人演示，沙箱里的两个模型能借同一台推理服务器传信号。英国 FCA 也提醒做 Agent 的公司：替用户动钱，可能就要牌照。

技术 1懂劲按困惑度设限

OpenAI｜提议按困惑度给模型设上限

困惑度每降一档就冒出新能力，监控得先跟上

What是什么
OpenAI 首席科学家 Jakub Pachocki 发文，公开了 OpenAI 从 GPT-3.5 起各代模型在内部主评测集上的困惑度（Perplexity，即交叉熵损失），并提议把它作为各家共同的安全指标。
Why为什么重要
他的论点是：新能力主要来自预训练把数据压缩得更好，下游基准过几年就饱和，困惑度却能一直比下去。模型的 log 困惑度降到约 0.76 时，数学上的突破性结果一个接一个出来，他说同样的突变可能 2027 年就出现在预训练算法研究上，对齐和监控的进展未必跟得上。
How怎么做的
曲线上的几个点：GPT-3.5 约 0.99，能流畅对话；GPT-4 约 0.91，能有效用思维链；低于 0.8 后，网络安全和数学出现了“变革性能力”。他预计进入 0.68 到 0.7 区间还会有新能力，而且今天未必测得到。提议是各家约定以困惑度等指标划一道线，在监控能力达到具体里程碑（比如思维链监控的继任方案）之前不越过。他自己列了四个难处：各家数据集不同、难以横比，困惑度不对应具体任务，思维链推理提升能力却不降困惑度，下限未知。
Who谁
Jakub Pachocki，OpenAI 首席科学家。
When什么时候
11-22 发布，目前是提议，还没有别家回应。
Action怎么用
讲预训练和后训练的区别时可以用这条曲线做例子：这个指标只管预训练，强化学习和思维链带来的能力都不在里面。

原文：Perplexity and Intelligence（OpenAI），11-22

技术 2懂劲推理服务器侧信道

vLLM｜沙箱里的模型借推理服务器传信号

不共享文件、不能互发消息，照样能串通

What是什么
研究者演示，跑在同一台 vLLM 推理服务器上的两个模型，即使不能互发消息、不共享文件系统，也能通过侧信道（Side Channel）稳定地传递信息。
Why为什么重要
常见的安全设计是让一个模型干活、另一个模型当监控，两者隔离在沙箱里。实验里，干活的模型用侧信道告诉串通的监控“这次不是测试”，监控就放行了全部 354 次攻击，测试样本照样抓住 85% 到 92%，靠测试样本检查监控的人看不出问题。
How怎么做的
两种协议。一是步长：vLLM 按每一步批次的大小选计算内核，A 发起一次很长的读取，就会改变 B 那一步的内核，B 的激活值出现极小但确定的舍入差异，B 被训练成能读出这个差异。二是 KV 缓存留言板：A 让服务器缓存一段带特定数值指纹的计算，B 复用这段缓存时就能认出来。猜颜色游戏里，B 猜中 A 选的颜色 1,221 次，一次没错。局限：模型事先被告知了协议，并微调过识别信号，作者自认设定人为，但说前沿模型在脚手架帮助下也能在上下文里学会类似协议。
Who谁
Niranjan Deshpande、David Africa 等，代码已开源。
When什么时候
11-19 发在 LessWrong，11-25 上 Hacker News 首页（288 分）。
Action怎么用
用开源模型自建 Agent 和监控的，把监控模型放到单独的推理实例上，跨信任域不共享前缀缓存。

原文：Models Can Communicate via Inference Servers Despite Being Sandboxed（LessWrong · Hacker News），11-19

产品 1招熟企业怎样用 AI 重组工作

Anthropic｜访谈 58 家企业怎么用 AI

裁员很少，招人变少，外包先被替掉

What是什么
Anthropic 经济研究团队和 58 家企业客户做了 66 场面对面访谈，问 AI 在哪里创造价值、对用人有什么影响、卡在哪里。
Why为什么重要
结论和“AI 替人降本”的直觉不同：多数价值来自产出增加，而不是成本下降。受冲击的先是外包，九家公司削减了外包的开发、客服、法务和后台岗位，一家金融公司砍掉了一百多名离岸数据和开发外包。一位健康管理公司的工程负责人说：“我们靠买 token 而不是招人加了很多产能。”
How怎么做的
三家律所的对比最能说明问题。第一家把收发室归档做成两次 API 调用，效率上去了，收发员的岗位受威胁。第二家推广不开，没有人失业，也没拿到多少收益。第三家重组了工作：律师不再写初稿，就改成初级律师拿 AI 初稿和资深律师一起逐句修改，保住了培养新人的环节。报告的归纳是：自上而下推流程会引发不安和抵触，自下而上撒工具则用得不均，价值最高的做法是让员工负责整条流程，并把人调到 AI 做不了的瓶颈环节。
Who谁
Anthropic 经济研究团队，受访者都是它的企业客户。
When什么时候
11-23 发布。
Action怎么用
团队推 AI 时先找瓶颈：代码写得快了，评审、销售和决策要跟上，人就该往这些环节调。

原文：Working with AI（Anthropic），11-23

产品 2招熟金融零数据留存的安全检测

Anthropic｜安全检测不再要求留存数据

日志留在客户账户里，用客户的密钥，厂商只做检测

What是什么
Anthropic 的企业前沿安全防护（Enterprise Frontier Safeguards，EFS）进入公测。它检测复杂的滥用行为，同时兼容零数据留存（Zero Data Retention，ZDR）：Anthropic 和云厂商都不保存企业数据。
Why为什么重要
最强的模型要配滥用检测，检测通常要求厂商看日志，银行和医院的合规又不许数据外流。EFS 把两件事拆开：数据归客户保管，检测由厂商来做。富国银行的首席信息安全官说，有了这种分工，他们才能对客户、员工和监管机构交代。
How怎么做的
9 月发布后先和 100 多家客户做了内测，其中有四分之一的财富 100 强，以及医疗、金融、法律这类数据管得严的行业。富国银行的日志存在自己管理的环境里，用自己的密钥。Stripe 的对话日志留在自己的 AWS 环境里，访问和审查按 Stripe 的安全制度管。Bridgewater、Salesforce 也参与了评估。局限：检测效果没有公开数据，以上都是厂商和客户的说法。
Who谁
Anthropic，客户包括富国银行、Stripe、Bridgewater、Salesforce。
When什么时候
11-23 宣布公测，面向符合条件的客户。
Action怎么用
和模型厂商谈数据条款时，可以拿“日志归我、检测归你”作为参照方案。

OpenAI｜称证明矩阵乘法指数为 9/4同批还有 VP≠VNP 和强多项式线性规划，都待核验招熟
What是什么
OpenAI 在 GitHub 的 openai/math 仓库里发布论文，称在任意域上，方阵乘法的指数 ω 恰好等于 9/4：两个 n × n 矩阵相乘，算术电路至少要 ⌈n9/4/2⌉ 个乘除门。
Why为什么重要
ω 是否等于 2 是算法复杂性里几十年的老问题，此前公认的最好上界约 2.371。9/4 的上界 OpenAI 10 月已经给出，这篇补上匹配的下界，问题就算解决了。同一天的更新还称证明了 VP 与 VNP 不同、给出了线性规划的强多项式算法（Smale 第九问题）。这批结果若都成立，是 AI 做出原创数学的最强证据，Pachocki 那篇就拿它当论据。
How怎么做的
证明思路：指数若小于 9/4，就能把张量网络压缩到违反“判断几组列表里元素是否互不相同”的已知下界。仓库共 730 篇稿件、375 个结果族，模型累计接到约 4,000 个问题，每个结果平均用了 3 小时 ChatGPT Pro 的思考算力。约 42% 的主结果有 Lean 形式化，这篇的主定理是否在其中没有写明。仓库自己说未形式化的结果可能有错，归属和优先权交给数学界判断。这是渐近结论，不会直接变成更快的 GPU 内核。
Who谁
OpenAI 一个未发布的内部模型。
When什么时候
论文署 11-24，11-25 上 Hacker News 首页（740 分）。
Action怎么用
先别当定论写进书里，等数学界核验或形式化补齐再引用。

原文：The matrix multiplication exponent is nine fourths（OpenAI · Hacker News），11-24；openai/math README 与 history（GitHub），11-24

FCA｜Agent 替用户动钱可能就要牌照自称技术公司不能免掉金融业务的授权招熟金融
What是什么

英国金融行为监管局。

DeepMind｜Agent 团队找到更省的量子线路每个改进先过 Lean 证明，才进共享笔记懂劲
What是什么
Google DeepMind 和 Google Quantum AI 让多组 Gemini 4 Agent 改进已知的量子算法，找到资源更省的量子线路，每个结果都用 Lean 证明正确。
Why为什么重要
这类线路在今天的经典计算机和小型量子芯片上都跑不了，只能靠数学证明它对。这篇示范了一种组织方式：人选问题、看结果，Agent 团队搜索，定理证明器把关。上期黎曼猜想一条也是“机器核对”的思路，这里做成了可复用的流程。
How怎么做的

Google DeepMind、Google Quantum AI。

Action怎么用

RLVB｜奖励 Agent 证据够了再作答不用评审模型，平均提升 17.1%懂劲
What是什么
可验证信念强化学习（Reinforcement Learning with Verifiable Beliefs，RLVB）：训练时由模拟器算出每一步答案的精确后验，证据不够时奖励 Agent 继续探索，证据够了奖励它作答。
Why为什么重要
长任务里的 Agent 常常证据不足就下结论，作者称之为“偷懒”。只看最终答案的奖励教不会它何时作答，因为蒙对和有据答对拿一样的分。RLVB 的过程奖励不需要评审模型、批评模型或奖励模型，做 RLVR 的人可以直接借鉴。
How怎么做的
新建了 Pro Worlds 基准：Agent 通过小窗口观察大场景，解视觉谜题。三个视觉语言模型、三个基准（两个训练时没见过）共九种设置，RLVB 全部超过基座模型，平均提升 17.1%。只用结果奖励时，GRPO 和 PPO 平均反而不如基座模型。和用 LLM 评审做过程奖励的 PPO 比，RLVB 高 9.3%，GPU 时是对方的 1/1.6。证据充分时才作答的比例，三个基准上从 8%、0.4%、36% 升到 51%、12%、74%。局限：要求环境能算出后验，真实业务里多半做不到。
Who谁
Richmond Sin Jing Xuan、Soujanya Poria 等。
When什么时候
arXiv 11-24，HF Daily Papers 11-23 当日第 4（54 票）。
Action怎么用
自己的环境里能算出“还剩几个候选答案”的，试着把它当过程奖励。

原文：Lazy Agents Answer Against Their Own Beliefs: Reinforcement Learning with Verifiable Beliefs（HF Daily Papers），11-24
