技术 1懂劲形式化验证规模化

Claude 为 239 个开源入口写出“不崩溃”证明

写证明这一步可以交给模型了

What是什么
Claude 为 123 个开源库的 239 个模糊测试入口写出形式化证明：任何不超过 64 MB 的输入，都不会让程序崩溃。
Why为什么重要
形式化验证比测试彻底，但证明极贵：seL4 内核写代码用了 2 人年，验证用了 20 人年，过去只有内核、航电这类系统用得起。现在写证明可以交给模型，人只需审规格。
How怎么做的
证明写在 RISC-V 汇编层，约 1.8 亿行，全部通过定理证明器 Rocq 的检查。过程中修了数百个模糊测试多年没发现的 bug。只证明了“不崩溃”这一个性质，不代表没有别的 bug。
Who谁
Anthropic；配套的 Claude skill 由 Theorem 公开。
When何时
10-22 发布，证明已公开。
Action我们做什么
挑一个解析器类的小模块，把现有模糊测试转成规格，用这个 skill 试一次；跑通后，把“证明通过”设成 CI 的一道门。

原文：LLMs are making formal software verification feasible at a much larger scale（Anthropic），10-22

技术 2招熟OpenShell 开源

NVIDIA 开源 Agent 沙箱 OpenShell

权限由运行时决定，不靠提示词

What是什么
NVIDIA 开源的 Agent 运行时 OpenShell，许可证是 Apache-2.0。
Why为什么重要
权限从模型挪到了运行时，模型被提示注入诱导，也越不过沙箱。受监管行业做安全审查，查的就是这一层。
How怎么做的
每个 Agent 跑在独立沙箱里，出站连接逐个过策略检查。Agent 拿不到真实凭证，请求发往批准的地址时才由代理注入。有风险的策略变更要人审批。
Who谁
NVIDIA。
When何时
10-22 开源，还没有公开的生产案例。
Action我们做什么
金融、医疗 Agent 的工具调用统一过沙箱；凭证由代理注入，不进模型上下文；网络白名单和策略变更走审批。

原文：NVIDIA/OpenShell（GitHub），10-22

产品 1懂劲医疗儿科出院文书 RCT

医生审核 AI 文书，22 处缩写错误漏改 16 处

通顺的错误最难发现

What是什么
一项随机对照试验：儿科急诊出院文书，一组由本地开源 LLM 起草再经医生审核，一组用模板组装。
Why为什么重要
多出来的句子一眼能看到，展开错的缩写读着通顺，审核时容易滑过去。只统计“医生改了几份”，看不出漏了什么。
How怎么做的
153 名儿童入组，分析了 117 名。两组家属理解度没有差异，送出的文书没有严重差错（0/117）。医生改了 58 份草稿中的 48 份；22 处无依据的添加删掉了 18 处，22 处错误的缩写展开只纠正了 6 处。
Who谁
蒙彼利埃大学医院。
When何时
10-22，预印本；漏检的数字来自探索性分析。
Action我们做什么
保存原始记录、AI 草稿、医生终稿三份并自动比对差异；缩写、剂量、单位单独高亮；定期抽样统计审核漏检率。

原文：From clinician review to measurable human oversight of AI-drafted paediatric discharge documents（medRxiv），10-22

产品 2招熟金融新 · 银行对外部 Agent 只开只读

大银行只许外部 Agent 读账户，不许动钱

读写分开会成为默认边界

What是什么
几家银行对 Meta Muse 这类个人 Agent 代客户操作银行账户的表态。
Why为什么重要
读和写分开授权，正在成为金融 Agent 的默认边界。面向客户的 Agent 不按这条边界设计，上线后会被银行拦下。
How怎么做的
摩根大通不允许外部 Agent 拿客户凭证代为登录；经 Plaid 等连接器仍能读余额，但不能转账、付账单，并提醒客户授权外部 Agent 可能带来责任转移。嘉信理财每周拦截数十次 Agent 转账尝试。反过来，中小企业银行 Finom 主动给 Claude、ChatGPT 开了只读的 MCP 接口。
Who谁
摩根大通、嘉信理财、加拿大皇家银行（考虑限制）、Finom。
When何时
10-13 至 10-22 陆续表态，还不是行业标准。
Action我们做什么
金融 Agent 默认按只读设计；转账、付款交回银行渠道，由客户确认；产品条款写清客户授权后责任归谁。

原文：Banks move to limit agents' access to customer accounts（Finextra）；JPMorgan Chase blocks outside AI agents from accounts（The Paypers）；RBC CEO weighs blocking Meta's Muse AI agent as banks close ranks（Crypto Briefing），10-22
