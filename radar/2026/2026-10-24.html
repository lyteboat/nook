01本期必懂（20%）

只读这一节，也能抓住本期八成的价值。

1

Agent 的能力要建在开放标准上，模型可以换，能力不能丢 招熟

心法
Agent 正在分成三层公共基础设施：技能包（Agent Skills）管“会做什么”，模型上下文协议（Model Context Protocol，MCP）管“能连什么”，沙箱运行时（Sandbox Runtime）管“能碰什么”。这和 Java 里面向接口编程是一个道理：标准是接口，模型是实现，实现可以替换。
招式
把金融或医疗产品里一个固定流程（比如一类单据的审核）写成一个 SKILL.md；试一下 NVIDIA 的 OpenShell，看能否作为 Agent 的沙箱。
依据
Agent Skills 捐给 Linux 基金会下的 AAIF，已有 70 多个平台接入，累计发布 100 万个 skill（Anthropic，10-22）；OpenShell 开源，约 1 万星（10-22）。
2

人工审核不是兜底，它本身也要被测试 懂劲

心法
代码评审（Code Review）代替不了测试，同理，“医生看过了”也不等于没错。审核者会漏，漏多少要靠记录来度量。
招式
产品里保存“AI 生成了什么、人改了什么、哪些内容没有依据”三份记录；按 Agent 的自主程度分级配置审批，自主程度越高，复核越严。
依据
儿科出院文书随机对照试验（RCT）中，医生漏掉了 22 处无依据添加里的 4 处（medRxiv，10-22，预印本，见第四节的图）；FSB 第 10 条要求人工监督按自主程度配置（FSB，10-15）。
3

金融 Agent 先做流程和审阅，别指望它跑赢市场 招熟

心法
LLM 擅长对照标准做判断，不擅长预测。有明确规则和标准答案的环节，就是 Agent 最先落地的地方。
招式
金融产品选题从调查、对账、审阅、客服切入；给 Agent 的产出定一套评分标准（Rubric），用它做自动评审。
依据
Starling 的金融犯罪调查 Agent 17 秒完成一次调查（Finextra，10-21）；Terminal X 的评审 Agent 按 54 项标准审阅，与资深审阅者一致率 88.6%（OpenAI，10-20，厂商自报）；Quant-Arena 中没有一个 LLM 跑赢 A 股等权组合（arXiv 2610.30113，10-21）。

03宏观：格局与监管

前沿实验室开始公开谈“加速已经开始”，同时呼吁放慢

Jack Clark 在 IMF 曼谷会议上用两项基准说明 AI 正在加速科研，同时主张在生物等领域保持严格的人类监督（Import AI 477，10-19）。

我的看法：这是前沿实验室联合创始人对宏观政策听众的发言，立场鲜明，数字可以引用，判断要和其他来源对照着看。

开源模型成了地缘政治议题

  • 招熟中国商务部提出前沿模型发布前审批的征求意见稿，美国国土安全部限制 DeepSeek 成为联邦采购供应商。（Interconnects，10-20）
  • 招熟Nathan Lambert 认为 Meta 的 Muse Spark Open 是目前最强的美国开源权重（Open Weights）模型，但它的定制许可证限制较多。（Interconnects，10-17）
  • 懂劲SemiAnalysis 实测华为昇腾 950PR 在 BF16 矩阵乘上的中位利用率为 41.5%，H100 为 46.8%，绝对性能介于 A100 和 MI300X 之间。（SemiAnalysis，10-21，💰 部分付费）

我的看法：在金融、医疗这类受监管行业选开源模型，许可证和合规风险要和性能一起评估（对应第 3 章“模型选型”）。

04中观：平台、模型与工具

Agent 的三层基础设施都在走向开放标准

三层各管一件事，本周每一层都有动作。对受监管行业，最下面的沙箱层最关键，它决定 Agent 能否通过安全审查。

  • 招熟OpenShell 让每个 Agent 跑在隔离沙箱里，网络请求逐一过策略检查，Agent 拿不到真实凭证，凭证只在请求发往许可的地址时才注入。Hacker News 381 分。（GitHub，10-22）
  • 招熟OpenAI 的前沿模型和 Codex 工作流进入 Google Cloud 的 Model Garden 和 Marketplace。（OpenAI，10-21）
  • 懂劲Claude 在 123 个开源库的 239 个模糊测试（Fuzzing）入口上，于 RISC-V 汇编层面完成了“不崩溃”性质的形式化验证（Formal Verification），证明约 1.8 亿行 Rocq，顺带修复了数百个模糊测试多年没发现的 bug；文章提醒，形式化验证不等于没有 bug。（Anthropic，10-22）

05行业：金融 AI

监管给出了框架，机构在流程环节密集上线 Agent

一周之内，从监管框架到卡组织、银行、投研机构都有动作，但一项基准提醒我们，Agent 的价值在流程，不在预测。

06行业：医疗 AI

人工审核拦不住所有错误，监督需要被记录和度量

儿科急诊出院文书的随机对照试验里，117 名儿童入组分析，LLM 起草与模板组装两组家属理解度没有差异，但医生审核时漏掉了一部分 AI 引入的问题。

阶段信号说明来源
招熟州级医疗 AI 监管工作组美国州医学委员会联合会召集 22 人工作组，成员来自 AMA、AHA、Anthropic、Elevance Health，讨论自主临床 AI 的监管指引STAT，10-14 💰
懂劲AI 病历与人工病历对比模拟配对研究中，AI 起草的病历质量略高、错误更少，以遗漏为主；严重错误的证据尚不充分（预印本）medRxiv，10-19
招熟OpenAI 收购 Orchestra Bio药物研发协作平台，并入生命科学产品线 RosalindOpenAI，10-20
懂劲数千个 Agent 分析脑细胞数据与 Scripps 等机构合作，分析数百万个小鼠脑细胞的 CRISPR 数据，32 分钟生成假说图谱；盲评中专家 75% 的情况偏好多 Agent 报告；结论仍待实验验证OpenAI，10-21
招熟Anthropic 生命科学访问学者合作 8 至 12 周，成果开源，申请期约 14 天Anthropic，10-22

对医疗产品的启示：编辑次数和满意度评分说明不了审核者漏掉了什么，产品要记录 AI 写了什么、人改了什么；监管从州一级起步，合规设计要预留按地区调整的空间。

待验证：量子位报道清华 AIR 孵化的多智能体方案让“医生 AI 分身坐诊医院”（量子位，10-21），标题偏夸张，需要找到一手资料再判断。

07AI 产品

好产品不等于被用起来，模型选型要看任务类型

  • 招熟Lenny Rachitsky 评价 Claude Duet 是他见过最精致的个人 Agent 发布，但自己还是忘了用：一个主动型 Agent 从不主动提醒，又缺少桌面端和多人协作，留存就成问题。（Lenny's Newsletter，10-21，💰 部分付费）
  • 招熟同一作者测评 Meta 的 Muse Wonder：Agent 类任务排第一，设计和视觉工作明显偏弱。（Lenny's Newsletter，10-14）

可借鉴的做法：Agent 产品要设计“什么时候主动出现”，这比功能完整更影响留存；模型按任务类型分开选（对应第 13 章“产品设计”）。
